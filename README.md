# Cloud-Based Food Ordering System

## Project Description

The Cloud-Based Food Ordering System is a Python-based application that allows users to view food items, place orders, and view all orders. The system uses a database to store food and order details.

## Features

* View food menu
* Place food orders
* Calculate total price
* Store customer and order details
* View all orders
* Simple and user-friendly menu

## Technologies Used

* Python
* SQLite Database
* Google Colab

## How to Run

1. Open Google Colab.
2. Create a new notebook.
3. Copy and paste the Python program.
4. Click the Run button.
5. Select the required menu option.
6. Enter customer name, food ID, and quantity.

## Sample Food Menu

1. Pizza – ₹150

4. Biryani – ₹180

## Database

The system uses SQLite to store:

* Food details
* Customer details
* Order details
* Quantity
* Total amount
